## Criterios a evaluar

| Criterio | Requisito | Detalle |
|---|---|---|
| **Problema a resolver** | Obligatorio | Describir el problema, quién lo tiene y por qué una solución IoT lo resuelve. |
| **Herramientas de automatización** | Obligatorio (mínimo 1) | Node-RED, n8n, Home Assistant, Grafana, IFTTT o Make. |
| **Base de datos** | Obligatorio | Libre: PostgreSQL, MySQL, etc. |
| **Protocolo de comunicación** | Obligatorio (mínimo 1) | HTTP (API / endpoint / webhook) o MQTT. |
| **Dispositivos y datos** | Opcional | Hardware real o simulado (ver abajo). |
| **Visualización** | Opcional | Grafana, dashboard de Node-RED o Home Assistant. |

### Dispositivos y datos (opcional)

- **Hardware real:** ESP32 / ESP8266 (ESPHome, Tasmota o código propio).
- **Simulado:** Wokwi, o un script en Python que genere datos e interactúe con el sistema.
